# auditor-pesquisa-style — análise

**Complexidade:** média — quatro modos de resposta, regras de domínio, mas sem fluxo encadeado

| Forças | Fraquezas |
|---|---|
| • Separa os modos (execução, clarificação, auditoria, apoio à decisão) e evita confirmação ritual.<br>• A regra sobre resultados quantitativos (pseudorreplicação, unidade de análise) vale para qualquer pesquisa. | • Precisa ser preenchida: o bloco "Papel" é um molde com os eixos de exemplo do projeto de origem.<br>• Três das quatro regras de domínio são específicas do projeto de origem e devem ser substituídas. |

| Oportunidades | Ameaças |
|---|---|
| • Pode ser adaptada para qualquer pesquisa com mais de um eixo metodológico. | • Se o molde não for preenchido, o modelo aplica regras de um domínio alheio. |
